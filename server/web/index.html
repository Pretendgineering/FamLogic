Family

Everyone in your family's FamLogic. Parents look after the family and can read their children's chats; children use the app without family settings, and younger ones sign in with a join code instead of a password.

Roles: Admin (a parent who can use these admin pages; only the main admin can make admins), Parent, Older child (may use a password), Younger child (joins with a code from you, no password), and family members who don't use the app (such as a baby), so events and reminders can include them.

    Access & Control

    What each person can use, see and do. Open someone to set it up; changes save straight away and reach their device within a minute. Parents can use everything; children start from a preset you can change bit by bit.

    Parent PIN
    Unlocks settings on children's devices and family displays.

      Devices

      Every signed-in phone and tablet. A person can use several; their phone's location wins over a tablet's.

      Phones and tablets

        Family displays

        A wall tablet or TV showing the family's day. It has its own sign-in (no location, can't post), and you can sign it out here any time.

        Settings

        Switch parts of FamLogic on or off for your whole family. Modules marked coming soon can be chosen now and switch on when they arrive.

          Backup and restore

          A backup is one zip of everything: people, devices, fences and settings, every chat with its photos and voice clips, the feed, Steward chats, and the whole notes vault. It holds password hashes, so keep it as safe as the server. The server also keeps a copy of the data file and chats each day in backups/.

          Restoring replaces everything with the backup, then restarts the server (about ten seconds). What was there moves to backups/before-restore-… first, so nothing is lost. The notes go to the vault folder the server uses now, so to move the vault: download a backup, point VAULT_DIR at the new folder, restart, then restore.
